§ 01

摘要

三句话带走整份报告

DeepSeek V4 是中国 AI 实验室 DeepSeek 于 2026 年 4 月 24 日发布的第四代旗舰大模型，包含 V4-Pro（~1T 参数）和 V4-Flash（284B 参数）两个变体。核心创新是 Engram 条件记忆机制，实现 O(1) 复杂度的 1M token 上下文处理，同时在 SWE-bench Verified 达到 81%，逼近 Claude Opus 4.6 的 80.8%。

三句话带走

  1. 开源阵营首次在编码基准上逼近闭源前沿。V4-Pro 在 SWE-bench Verified 达 81%，仅比 Claude Opus 4.6 高 0.2 个百分点，但成本仅为后者的 1/10。
  2. Engram 条件记忆是架构核心差异点。不同于标准 Transformer 的全局注意力，Engram 用条件激活的记忆块实现 O(1) 上下文访问，1M token 窗口无溢价。
  3. 定价策略激进：$0.30/MTok 输入、$3.48/MTok 输出。比 Claude Opus 4.6 便宜 87%（输入）和 77%（输出），直接冲击开源 + API 双市场。

§ 03

架构创新

Engram 条件记忆、MoE 拓扑、多模态生成

Engram 条件记忆机制

这是 V4 最核心的架构创新。标准 Transformer 的自注意力复杂度是 O(n²)，处理 1M token 时计算量爆炸。Engram 用条件激活的记忆块替代全局注意力：

  • 分块存储：上下文被切分成固定大小的"记忆块"（memory chunks），每块独立编码。
  • 条件检索：生成 token 时，模型先用轻量级检索器（retriever）判断需要激活哪些记忆块，只对相关块做注意力计算。
  • O(1) 访问：检索器复杂度是 O(log n)，激活块数量固定（如 k=8），总复杂度降至 O(k) ≈ O(1)。

这让 V4 能以无溢价方式支持 1M token 上下文 —— 处理 1M token 的成本与处理 128K token 相当。

Mixture-of-Experts 拓扑

V4-Pro 采用稀疏 MoE 架构：1T 总参数分布在 ~128 个专家（experts）中，每个 token 仅激活其中 4-6 个专家（~37B 参数）。这种设计在保持大容量的同时，推理成本接近 40B 稠密模型。

原生多模态生成

V4-Pro 支持文本 → 图像生成（类似 DALL-E 3），但不支持图像 → 文本理解（即不能"看图说话"）。这是与 GPT-4o / Claude 3.5 Sonnet 的主要差距之一。

定价策略

API 定价、成本对比、市场冲击

核心观察：

  • V4-Pro 输入成本比 Claude Opus 4.6 便宜 87%（$0.30 vs $2.40）。
  • 输出成本便宜 77%（$3.48 vs $15.00）。
  • 1M token 上下文无溢价，而 Claude / GPT 在超过 128K 后价格翻倍。

市场冲击

这种定价策略对两个市场形成直接冲击：

  1. 闭源 API 市场：在编码任务上，V4-Pro 性能逼近 Claude Opus 4.6，但成本仅为后者 1/10。企业客户（尤其是成本敏感型）有强动力迁移。
  2. 开源自托管市场：V4-Pro 权重开源，企业可自托管（需 8×H100 或 4×H200）。对于月调用量 >1B tokens 的场景，自托管成本可能低于 API。
§ 06

对 DeepInsight 的启示

放回我们自己项目语境

启示 1

长上下文成为标配

V4 的 1M token 无溢价策略，意味着"上传整本书 / 100 页 PDF"不再是奢侈品。DeepInsight 的 PDF 分析 pipeline 可以考虑直接塞全文而非 chunk + retrieve，简化架构。

启示 2

开源 + API 双轨并行

V4 同时提供开源权重和 API 端点，让用户根据场景选择。DeepInsight 未来如果做 self-hosted 版本，可以参考这种"开源 core + 云端增强"的模式。

启示 3

成本优化是差异化点

V4 用 MoE + Engram 把成本压到闭源模型的 1/10，这是技术创新直接转化为商业优势的案例。DeepInsight 的 LLM 调用层也应该做成本可观测（per-user / per-report token 计数）。

启示 4

编码能力是新战场

SWE-bench 从"学术基准"变成"产品卖点"（V4 官网首屏就是 81% 这个数字）。如果 DeepInsight 未来做"代码洞察"（分析开源项目架构），V4 是值得评估的后端选项。
